# 🤖 Virtual Assistant

A full-stack Virtual Assistant web application built with a modern frontend and backend architecture.

## 🚀 Features

- 🎙️ Virtual assistant interaction
- 🔐 User authentication
- 👤 User account management
- 💬 Assistant-based interaction
- 🌐 Full-stack architecture
- 📱 Responsive frontend
- 🔒 Environment variable support
- ⚡ Fast and modern React frontend
- 🛠️ REST API based backend
